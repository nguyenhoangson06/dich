Tạo phụ đề tiếng Việt từ video

Nhận dạng giọng nói → dịch sang tiếng Việt → xem trước và tải file .srt. Âm thanh được xử lý ngay trên máy bạn.

Hãy chọn một file để bắt đầu.

Lần đầu chạy sẽ tải model về trình duyệt (cần Internet). Phần dịch dùng dịch vụ MyMemory nên cũng cần Internet. Video dài sẽ tốn nhiều RAM và thời gian.

File .mp4 xuất ra chứa phụ đề tiếng Việt dạng track riêng (không mã hóa lại nên rất nhanh, giữ nguyên chất lượng). Bật phụ đề trong VLC, QuickTime, trình phát điện thoại... là thấy. Muốn ghi cứng phụ đề vào hình, dùng file .srt với CapCut/VLC hoặc script Python translate_subtitle.py. Bấm vào một dòng bên dưới để nhảy tới đoạn đó.
